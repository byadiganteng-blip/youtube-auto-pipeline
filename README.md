# Complete YouTube Pipeline - Per Part Upload

## Features (ALL PRESERVED)

1. **Anti-Detect Bot** - Random UA, delay, fingerprint
2. **Content Detection** - Anime, Manhwa, Donghua, Manga, Gaming
3. **Watermark Remover** - Auto detect + remove
4. **Split per Part** - 5 menit per part
5. **Auto Hashtag** - Content-aware
6. **Auto Title per Part** - Judul unik tiap part (NEW)
7. **Auto Upload per Part** - Upload otomatis tiap part (NEW)
8. **Preserve Audio** - FFmpeg merge audio
9. **Universal Downloader** - YouTube, FB, TikTok, IG
10. **GitHub Actions** - Full automation

## Cara Pakai

1. Buka Actions
2. Pilih "Complete Pipeline + Per-Part Upload"
3. Isi:
   - video_url: URL video
   - method: blur/inpaint
   - part_duration: 300 (5 menit)
   - auto_upload: true/false
4. Klik Run workflow
5. Tunggu proses
6. Download hasil dari Artifacts/Releases

## Fitur Per-Part

Setiap part akan:
- Split otomatis (5 menit)
- Watermark dihapus
- Audio preserved
- Judul unik: "PART X - Title"
- Hashtag auto-generated
- Upload otomatis (jika enabled)
